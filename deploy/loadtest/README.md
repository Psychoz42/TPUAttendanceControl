# Нагрузочный тест

Имитирует утренний пик: занятия меняют код раз в 10 секунд, студенты отмечаются новыми TLS-соединениями. Запускать с другой машины, а не на самом сервере, иначе генератор отнимет у сервера процессор. Тест пишет в базу и работает с тестовыми аккаунтами, поэтому на сервере с настоящими данными его не запускать.

## Подготовка

На время теста на сервере нужны тестовые пользователи: 15000 студентов `s00001` и 1500 преподавателей `t0001`, пароль `pass`. Пока они загружены, в сервис может войти кто угодно, поэтому после теста сразу верните настоящий файл. На компьютере из корня репозитория:

```bash
go run ./deploy/loadtest -gen-users users-test.txt
scp users-test.txt tpu:/opt/tpu/TPUAttendanceControlBackend/deploy/
```

На сервере в папке `deploy`:

```bash
cp users.txt users.txt.bak && mv users-test.txt users.txt && chmod 644 users.txt
docker compose restart backend
```

На машину, откуда идёт тест, положите копию `JWT_SECRET` сервера в файл `jwt.secret` вне репозитория: токены подписываются этим секретом. После теста файл удалите.

## Запуск

```bash
# реалистичный пик
go run ./deploy/loadtest -url https://<домен>/api/v1 -secret-file jwt.secret -classes 500 -students 10000 -window 2m

# все студенты за минуту и большая лекция
go run ./deploy/loadtest -url https://<домен>/api/v1 -secret-file jwt.secret -classes 1000 -students 15000 -window 1m -lecture 300
```

Для локального стека с внутренним сертификатом Caddy добавьте `-insecure`. Параметр `-logins N` добавляет N логинов в секунду, но с одной машины они быстро упрутся в лимит 100 в минуту на IP. Между запусками ждите пару минут, пока освободятся порты генератора.

На сервере в это время смотрите загрузку: `docker stats`.

Сравнивайте с замерами на двух ядрах настольного ПК без реальной сети:

| Сценарий | Запросов/с | p99 скана |
|---|---|---|
| 500 занятий, 10 000 студентов за 2 минуты, 15 логинов/с | 150 | 76 мс |
| 1000 занятий, 15 000 студентов за минуту, лекция на 300, 50 логинов/с | 405 | 100 мс |
| 1000 занятий, 15 000 студентов за 25 секунд | 700 | 176 мс |

Признак перегрузки: `p99` растёт до секунд, появляются `INVALID_QR` и `NET`. Код успевает истечь, пока запрос стоит в очереди.

## После теста

```bash
mv users.txt.bak users.txt
docker compose exec postgres psql -U postgres -c "DELETE FROM events WHERE event_owner ~ '^t[0-9]{4}$'"
docker compose restart backend
```
